# Поиск в ширину на PHP

Небольшая реализация алгоритма breadth-first search без сторонних зависимостей. Алгоритм находит кратчайший путь в невзвешенном графе и работает за `O(V + E)`.

## Возможности

- поиск кратчайшего пути между двумя вершинами;
- проверка существования пути;
- защита от циклов;
- валидация ссылок на неизвестные вершины;
- очередь `SplQueue` вместо дорогих операций с массивами;
- тесты и CI для PHP 8.1–8.4.

## Запуск примера

```bash
php examples/metro.php
```

Результат:

```text
Купчино → Звёздная → Московская → Парк Победы → Электросила → Московские ворота → Фрунзенская → Технологический институт 2 → Технологический институт 1 → Балтийская → Нарвская → Кировский завод → Автово
```

## Использование

```php
<?php

declare(strict_types=1);

use NoviKey\Graph\BreadthFirstSearch;

require 'src/BreadthFirstSearch.php';

$Graph = [
	'A' => ['B', 'C'],
	'B' => ['A', 'D'],
	'C' => ['A', 'D'],
	'D' => ['B', 'C'],
];

$Search = new BreadthFirstSearch($Graph);

var_dump($Search->HasPath('A', 'D'));
var_dump($Search->FindPath('A', 'D'));
```

`FindPath()` возвращает путь вместе с начальной и конечной вершинами. Если вершина неизвестна или путь отсутствует, возвращается пустой массив.

## Проверка

```bash
composer test
```

Composer нужен только как удобная команда и для PSR-4 autoload. Сам алгоритм не использует внешние пакеты.

## Структура

- `src/BreadthFirstSearch.php` — алгоритм;
- `examples/metro.php` — пример на схеме метро;
- `tests/run.php` — компактный набор регрессионных проверок.
